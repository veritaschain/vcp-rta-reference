# Security Policy

This repository follows the [VeritasChain organization security policy](https://github.com/veritaschain/.github/blob/main/SECURITY.md), including its private reporting procedure and response targets.

Report suspected vulnerabilities to **security@veritaschain.org**. Include the affected repository, commit or version, reproduction steps, and expected impact. Do not publish sensitive details in a public issue. For an encrypted exchange, first request a suitable channel in a non-sensitive message; no verified public PGP key is currently published.

This is a reference implementation. Its examples and verification results do not establish protocol conformance or production readiness.
